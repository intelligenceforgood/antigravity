# Antigravity Workflows

This repository contains the centralized knowledge, architectural guidelines, and native workflows for the I4G team's Antigravity AI assistant.

By maintaining these centrally, we ensure consistent AI-driven development across all of the I4G multi-root repositories (`core`, `ui`, `ssi`, etc.).

## Directory Structure
- `workflows/`: Agentic-native workflows designed for autonomous execution.
- `knowledge/`: Architectural styles and constraints automatically loaded as Knowledge Items.
- `docs/`: Developer onboarding guides and cookbooks.
